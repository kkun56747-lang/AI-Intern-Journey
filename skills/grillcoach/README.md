# grillcoach

自适应需求拷问、独立决策与动态行动教练。

- **版本**：3.0（源自 Butler Intent & Action Coach 3.0）
- **核心能力**：目标澄清、多假设分析、必要追问、前提与可行性审查、方案对比、行动规划、执行中调整与复盘
- **使用原则**：事实与推测分离；不盲从、不无限提问；不虚构证据或成功率；保留用户的最终决策权

## 安装

将本目录的 `SKILL.md` 复制到你的智能体技能目录，例如 `~/.agents/skills/grillcoach/SKILL.md`。

宿主支持技能调用时，可使用 `$grillcoach`；具体加载方式取决于所用 Agent。
